Aplicativo para alerta sobre o consumo de água
Linguagem usada Python
Instruções:
Ao iniciar, escolha uma das opções, digite o número correspondente, após o enter, digite o consumo em volume (m³), na sequencia obterá o resultado em forma de aviso.
